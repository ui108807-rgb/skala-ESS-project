# ESS 배터리 수명 예측

동일 제조 공정의 리튬이온(LFP) 배터리라도 충전 조건 및 운용 환경에 따라 최대 5배까지 극심한 수명 편차가 발생합니다. 본 프로젝트는 배터리 초기 100사이클의 전압 미세 변형 신호와 충전 프로토콜 데이터를 활용하여, 수만 개의 셀이 직병렬로 연결된 에너지 저장 장치(BESS)의 조기 셀 열화 감지 및 최종 수명(Cycle Life)을 고정밀도로 사전 예측하는 머신러닝 파이프라인을 구축하는 것을 목적으로 합니다.


## 프로젝트 개요
- 데이터셋 : MIT-Stanford Battery Dataset (Severson et al., Nature Energy 2019)
- 학습 데이터 : Batch 1 (2017-05-12, 46개 셀 → Train 36개, Valid Hold-out 10개)
- 평가 데이터 : Batch 2 (2018-02-20, 39개 유효 셀) / 추가 검증 : Batch 3 (2018-04-12, 44개 유효 셀)
- 태스크 : Regression (Cycle Life 예측, $Y = \log_{10}(\text{Cycle Life})$)

## EDA

- **Cycle Life 분포**
  - **분포 형태 및 장단수명 비율 요약**: 수명 범위 392 ~ 1,935 사이클(평균 약 845사이클)로 동일 규격임에도 약 5배에 달하는 극심한 편차 확인. 우측 꼬리가 긴 비대칭 분포를 보이므로 정규성 확보를 위한 $\log_{10}$ 타깃 변환 채택.
  - **핵심 발견** : 단순 공칭 용량이나 초기 스펙만으로는 셀 수명을 판별할 수 없으며, 셀별 고유한 열화 궤적을 반영하는 비선형 피처 발굴이 필수적임.

- **열화 곡선 분석**
  - **장수명 vs 단수명 셀의 열화 속도 차이**: 단수명 셀은 초기 용량 감소율이 가파르며 500사이클 부근에서 EOL(80% 용량)에 도달하는 반면, 장수명 셀은 1,200사이클 이상 안정적인 방전 용량을 유지함.
  - **Knee point 존재 여부 및 발생 시점**: 용량이 완만하게 감소하다가 특정 시점 이후 급격한 절벽형 하락을 겪는 Knee point가 400~600사이클 사이에서 뚜렷하게 관측됨.
  - **핵심 발견** : 초기 100사이클 동안 내부 리튬 안정화로 인해 겉보기 방전 용량이 일시적으로 상승하는 현상(Capacity Rise)이 관측되어, 초기 단순 용량($Q_d$) 크기와 최종 수명 간의 상관관계는 거의 전무함(초기 용량의 기만성 확인).

- **$\Delta Q(V)$ 곡선 분석**
  - **Cycle 100 - Cycle 10 차이 곡선 형태**: 10번째 사이클 대비 100번째 사이클의 전압별 방전 용량 차이 곡선인 $\Delta Q_{100-10}(V)$는 $3.0\text{V} \sim 3.4\text{V}$ 방전 평탄 영역에서 뚜렷한 피크 및 곡선 뒤틀림을 형성.
  - **장단수명 셀 간 $\Delta Q$ 형태 비교**: 단수명 셀일수록 피크의 찌그러짐과 곡선의 면적 변화(분산)가 비약적으로 크게 나타남.
  - **핵심 발견** : $\Delta Q(V)$ 곡선의 로그 분산(`dQ_log_var`)은 최종 수명과 $r = -0.851$, 단독 설명력 $R^2 \ge 72\%$를 기록하여 배터리 내부 활물질 손실(LAM)과 리튬 석출(LLI)을 가장 정밀하게 대변하는 1위 핵심 지표임을 입증.

- **충전 속도(C-rate)와 수명의 관계**
  - **충전 프로토콜별 평균 수명 비교 결과**: 1단계 급속 충전 전류가 높을수록(예: 6C 충전) 평균 수명이 400~600사이클 수준으로 급감하는 반면, 완속 완화 충전(3.6C 이하) 셀은 1,200사이클 이상의 고수명을 기록.
  - **핵심 발견** : 충전 속도(C-rate)를 대변하는 평균 충전 시간(`mean_chargetime`)은 수명과 강한 양(+)의 상관관계($r = +0.784$)를 가져 수명 편차를 유발하는 핵심 외부 환경 요인임.

- **추가 확인한 내용 (온도 및 다중공선성 진단)**
  - **최고 발열 온도($T_{max}$)**: 고속 충전 시 내부 저항으로 인한 줄열(Joule heating)로 온도가 37℃ 이상 치솟는 셀일수록 SEI 피막 분해가 가속화되어 수명이 단축됨 ($r = -0.627$).
  - **다중공선성(VIF) 진단**: 전압 곡선 지표 간 VIF가 20 이상으로 극심하여 단순 선형회귀(OLS) 적용 시 가중치 진동 및 과적합 위험 확인 → 정규화 모델 도입 필수.


## Modeling

### 피처 엔지니어링 전략
EDA 결과를 바탕으로 다중공선성을 최소화하고 내부 미세 열화 신호와 외부 운용 환경을 모두 반영하는 **4대 핵심 피처셋**을 최종 확정:
1. `dQ_log_var`: $\Delta Q_{100-10}(V)$ 전압 미세 변형 분산(로그) → 내부 활물질 손실(LAM) 및 가용 리튬 감소(LLI) 포착
2. `mean_chargetime`: 초기 100사이클 평균 충전 시간 → 충전 프로토콜(C-rate) 속도에 따른 외부 열화 스트레스 반영
3. `mean_Tmax`: 초기 100사이클 평균 최고 온도 → 급속 충전 발열로 인한 음극 피막 열화 스트레스 반영
4. `std_QD`: 초기 100사이클 방전 용량 변동 표준편차 → 초기 용량 안정화(Capacity Rise) 구간의 변동성 반영

### 모델 선택 및 근거
- **후보 모델** : Linear Regression (OLS), Ridge, Lasso, ElasticNet, LightGBM
- **최종 모델** : **ElasticNet 회귀 모델 (L1 Lasso + L2 Ridge 결합 정규화)**
- **선택 이유** :
  - $\Delta Q(V)$ 전압 변형 지표들 간의 다중공선성(VIF > 20)을 L1/L2 동시 규제로 제어하여 회귀 계수의 발산 및 과적합을 차단.
  - 초기 전압 분산과 타깃 간 압도적인 선형 관계($r = -0.851$)를 가장 안정적이고 해석 가능하게(White-box) 결합.
  - 5-Fold CV를 통한 `alpha` 및 `l1_ratio` 자동 튜닝으로 최적의 일반화 가중치 도출.

## 오류 분석
- **모델이 가장 크게 틀린 셀의 공통점**:
  - Batch 2 내 1단계 충전 전류가 극단적으로 높았던 초고속 충전 셀(수명 400사이클 미만)에서 실제 수명보다 길게 예측하는 과대 추정(Over-prediction) 오차 발생.
- **원인 가설 및 개선 방향**:
  - **원인 가설**: Batch 1(학습셋)은 평균 수명 845사이클의 완속/장수명 중심이었던 반면, Batch 2(테스트셋)는 평균 수명 565사이클로 초고속 단수명 셀이 집중되어 **배치 간 분포 이동(Distribution Shift)**이 발생함.
  - **개선 방향**: Batch 3(평균 수명 893사이클)에서 오차가 13.93%로 급격히 정상화된 것으로 보아 모델 자체 결함이 아닌 학습 데이터 커버리지 문제임 → 초고속 충전 전용 비선형 도메인 가중치 또는 C-rate 구간별 층화(Stratified) 모델 앙상블 도입 필요.


## ESS 도메인 해석
- **이 모델을 실제 BESS에 적용한다면 어떤 의사결정에 활용 가능한가?**
  - **선제적 불량 셀 스크리닝**: ESS 현장 가동 초기(100사이클 이내)에 잠재적 조기 단수명 셀을 식별하여 모듈 밸런싱 및 보증 교체(Warranty) 조기 판정.
  - **화재 위험 방지**: $3.0\text{V}\sim3.4\text{V}$ 전압 왜곡을 통한 리튬 석출(Lithium Plating) 조기 감지로 내부 단락 및 열폭주(Thermal Runaway) 선제 차단.
  - **최적 충전 프로토콜 추천**: 충전 시간과 발열이 수명에 미치는 가중치를 역산하여, ESS 수익성과 수명 저하 간 최적 절충점을 찾는 동적 충전 제어 알고리즘 구현.
- **어떤 한계가 있으며, 실 배포를 위해 추가로 필요한 것은 무엇인가?**
  - **100사이클 관측 대기 시간(Latency)**: 초기 100사이클(약 3~5일) 소요를 10~20사이클 수준의 초조기 스크리닝으로 단축하는 경량 알고리즘 필요.
  - **가변 환경 데이터 부재**: 항온 챔버(30℃) 실험 데이터 기반이므로, 실제 사계절 외기 온도(-20℃~40℃) 및 불규칙 부하를 보정하는 동적 온도 파이프라인 결합 필수.
